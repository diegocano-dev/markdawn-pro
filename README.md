# MarkDawn Pro

Installable versions of **MarkDawn Writer Pro** and **MarkDawn Mind Pro**: https://pro.markdawn.net/

Without a license key they work like the free versions. Get a key on [Gumroad](https://diegocanodev.gumroad.com/).

- **Writer Pro**: Notion-style block dragging, columns, and mind maps and flowcharts you edit right on the page.
- **Mind Pro**: 27 layouts (org chart, timeline, Kanban, canvases such as the Business Model Canvas, Gantt roadmap…), PDF and Word import with AI-made indexes, 17 map styles, 30+ shapes, high-resolution and SVG export, and guided demos.
