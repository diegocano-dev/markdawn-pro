MarkDawn Licencias

Comprueba una clave de Writer Pro o Mind Pro y libera equipos cuando un cliente llega al máximo de 3. Tu token no se guarda en esta página ni se envía a ningún sitio salvo a Gumroad.

1. Tu token de Gumroad

¿Cómo consigo el token?
  1. En Gumroad: Settings → Advanced → Applications.
  2. Crea una aplicación: nombre «MarkDawn Licencias», icono cualquiera y en Redirect URI pon http://127.0.0.1.
  3. Pulsa Create application y luego Generate access token.
  4. Copia el token y pégalo arriba. No lo compartas: da acceso a tu cuenta de Gumroad.
